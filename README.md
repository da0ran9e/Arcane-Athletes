# Aetheria Grand Prix

Board game đua chiến thuật 3–6 người, bản web 3D nhiều người chơi (Node.js + WebSocket + Three.js).

```bash
npm install
npm start      # http://localhost:3000
npm test
```

- Luật gốc: `GAME_RULES_AND_ASSETS_MASTER.md`
- Đặc tả & tiến độ: `docs/` (bắt đầu từ `docs/SPEC.md`, `docs/PROGRESS.md`)
- Ngôn ngữ: `public/locales/*.json`
- Asset: thả vào `public/assets/` theo `docs/ASSETS.md`
- Triển khai / Cloudflare Tunnel: `docs/DEPLOY.md`
